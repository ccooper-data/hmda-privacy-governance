# Safety and Responsible Research Policy

## Allowed outputs

Only aggregate disclosure-risk statistics may leave the controlled analysis environment. Cohort tables must suppress cells below the configured minimum size.

## Disallowed activity

Do not submit suspected identities, row-level high-risk records, or identified auxiliary data in an issue, pull request, discussion, or artifact. Do not use this repository to link HMDA records to natural persons.

## Reporting a problem

Report code vulnerabilities through GitHub's private security reporting feature. For a privacy-methodology concern, describe the aggregate failure mode without including source records.
